Proyectos

Planify

Planify es una aplicación web que arma itinerarios para salir en Encarnación. Elegís tus gustos, tu presupuesto, el tiempo que tenés y con quién vas, y la app te recomienda lugares.

La hicimos en grupo con Milena Fleitas y Valentina Kranich usando HTML, CSS, JavaScript y Tailwind CSS. La presentamos en la feria del colegio.

Diario de aprendizaje

Avances

Aprendí a hacer páginas con HTML y a darles estilo con CSS. Después empecé a usar Bootstrap para que se vean bien también en el celular.

Desafíos

Lo que más me costó fue acomodar las cosas con CSS, porque a veces se movían para cualquier lado. Probando de a poco lo fui entendiendo.

Reflexión

Con Planify aprendí a trabajar en equipo y a presentar un proyecto. Quiero seguir aprendiendo JavaScript para hacer páginas más completas.
